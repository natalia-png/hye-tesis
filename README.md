# De lo Disperso a lo Organizado — App de Gestión de Proyectos H&E

Una plataforma web diseñada para optimizar la **planificación, comunicación y seguimiento de proyectos arquitectónicos en tiempo real**. El sistema centraliza la información entre arquitectos, ingenieros y clientes, mejorando la trazabilidad, reduciendo reprocesos y facilitando la gestión colaborativa mediante metodologías ágiles y un stack tecnológico moderno.

---

## Getting Started (Primeros Pasos)

Estas instrucciones te permitirán obtener una copia del proyecto funcionando en tu máquina local para desarrollo y pruebas.

La aplicación fue desarrollada siguiendo la metodología SCRUM y utiliza una arquitectura moderna basada en React, Node.js, Firebase y Tailwind CSS.

---

### Prerrequisitos

Herramientas necesarias para ejecutar el proyecto:

- Node.js (v18 o superior)
- pm o yarn
- Git
- Firebase CLI
- Editor de código (recomendado: VS Code)

Instalar Node.js: https://nodejs.org/

Instalar Firebase CLI: npm install -g firebase-tools
